# 🎮 Ghost Signal

**Endless Runner 3D** desarrollado en Unity 6.4 con C#

## 📖 Historia
KAI es un joven técnico que debe correr a través de mundos digitales 
para recuperar memorias perdidas y salvar a ARIA, una IA que contiene 
400 millones de recuerdos humanos.

## 🎯 Controles
- **Flechas izquierda/derecha** — cambiar carril
- **Espacio** — saltar
- **Flecha abajo** — deslizarse
- **Quantum Fall** — cámara lenta al chocar con obstáculos

## ⚙️ Tecnologías
- Unity 6.4
- C#
- Mixamo (animaciones)
- Universal Render Pipeline
